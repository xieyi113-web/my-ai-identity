# pptx

基于官方 `pptx` 技能规范提炼的 `.pptx` / `.potx` 制作、编辑与质量核查工作流，涵盖金字塔内容设计、去“AI 味”视觉红线、`pptxgenjs` 编码避坑指南、OOXML 模板编辑规范及三层质检清单。

## When to Use

- 用户要求从零新建可编辑的 `.pptx` 演示文稿或生成 `pptxgenjs` / `python-pptx` 脚本。
- 用户需要基于既有 `.pptx` 或 `.potx` 模板修改内容、增删或重组页面。
- 用户需要解析、提取现有 `.pptx` / `.potx` 文件中的文本、表格、图表数据或演讲者备注。
- 用户需要对已有 PPT 方案进行结构优化、专业排版设计或质量自检。

## Steps

### 1. 按任务类型选择技术路径

- **新建演示文稿**：优先编写 `pptxgenjs` 脚本，按结构化方式（主题、母版版式、占位符、章节）构建，避免一次性硬编码散落元素。
- **修改既有文稿或套用模板**：解压 `.pptx`（本质为 XML 压缩包）-> 先完成页面增删与排序 -> 再修改 `ppt/slides/slideN.xml` 内容 -> 重新打包校验。旧版 `.ppt` 需先转换为 `.pptx`。
- **读取与分析内容**：逐页提取标题、正文、表格、图表数据、图片替代文本与演讲者备注，确保全量读取不遗漏。

### 2. 构建金字塔内容与叙事流

- **一页一观点**：每页聚焦单一核心信息，标题直出结论且末尾不加句号。
- **金字塔结构**：结论先行 -> 执行摘要（预览各章节）-> 分章节展开 -> 结论与下一步行动。
- **匹配使用场景**：现场汇报（高管/会议）重视觉、少文字，按每页 1.5 至 2 分钟控制总页数；会前预读或离线审阅材料需保证文字自洽；分析型报告以图表与数据表为主。
- **演讲者备注**：讲稿统一写入 `slide.addNotes("...")`，严禁堆放在幻灯片画布内。

### 3. 执行视觉设计与去“AI 味”红线

#### 配色与视觉母题

- **主次分明**：1 种主色占 60% 至 70% 视觉权重，配 1 至 2 种辅助色和 1 种高对比强调色，严禁各色均分。
- **明暗夹心对比**：封面与封底用深色背景，正文用浅色（默认纯白 `FFFFFF` 或品牌色），形成节奏感。
- **统一视觉母题**：全篇选定 1 种克制的视觉符号重复使用（如圆角图框、纯色圆形图标）。
- **严禁 AI 套路装饰**：
  - 严禁在标题下方添加细装饰线（accent lines）。
  - 严禁添加通栏色条、页面侧边竖条、卡片单侧彩色边框（single-side borders）。区分卡片请用浅底色、克制阴影或图标。
  - 严禁默认使用米黄/奶油底色（`F5F5DC`、`FAF0E6`、`FAEBD7`、`FFF8E1`）或千篇一律的默认蓝。

#### 版式、字体与间距

- **杜绝纯文字页**：每页均应包含至少 1 项视觉元素（原生图表、图标、数据大字、对比列、时间轴或图片），避免连续重复相同版式。
- **字号层级与底线**：
  - 幻灯片标题：36-44pt 加粗，同类页面标题位置、字号与对齐方式必须完全一致。
  - 章节小标题：20-24pt 加粗。
  - 正文：14-16pt（左对齐，严禁居中），**绝对底线不低于 14pt**；放不下时删减文字、放大容器或拆页，不得强行缩小字号。
  - 注释/来源：10-12pt 浅灰色，底线不低于 10pt。
- **安全字体**：英文正文优先选用 Office 原生安全字体（Arial、Calibri、Cambria、Times New Roman），严禁默认使用 Aptos；中文优先选用系统通用无衬线字体（微软雅黑、黑体）。
- **留白规范**：页面四周最小边距 0.5 英寸，内容模块间距保持 0.3 至 0.5 英寸并全篇统一。

### 4. `pptxgenjs` 编码核心避坑清单

- **画布与实例**：添加页面前先设置 `pres.layout`（`LAYOUT_16x9` 为 10" x 5.625"，`LAYOUT_WIDE` 为 13.3" x 7.5"）；每个输出文件必须新建独立的 `new pptxgen()` 实例。
- **颜色格式**：十六进制颜色**严禁带 `#` 号，严禁使用 8 位含透明度色值**（如 `"FF0000"` 合法，`"#FF0000"` 或 `"00000020"` 会损坏文件）。透明度在填充/图片中用 `transparency: 0-100`，在阴影中用 `opacity: 0.0-1.0`。
- **对象复用与阴影**：`pptxgenjs` 会原地修改配置对象，严禁跨 `add*` 调用复用同一个选项对象；阴影 `offset` 必须大于等于 0（向上投影用 `angle: 270` 配正值）。
- **文本与列表**：字符间距属性为 `charSpacing`；列表项逐条设 `bullet: true`，严禁手写 `•` 符号，除末项外均设 `breakLine: true`，段间距用 `paraSpaceAfter`；非占位符 `addText` 需加 `isTextBox: true`；与线条或图标对齐时设 `margin: 0`；`rectRadius` 仅对 `ROUNDED_RECTANGLE` 生效；不支持原生渐变填充。
- **原生图表规范**：优先使用 `addChart()` 生成原生图表；堆积柱状图/条形图的 `dataLabelPosition` 仅允许 `ctr`、`inEnd`、`inBase`（用 `outEnd` 会损坏文件）；组合图使用次坐标轴时，必须同时配置两个 `valAxes` 和两个 `catAxes`。
- **XML 转义与结构**：`pres.company` 与 `defineSlideMaster()` 的 `title`/`masterName` 中的 `&` 必须写成 `&amp;`；严禁调换 `<p:presentation>` 子节点顺序。

### 5. 模板与 OOXML 编辑规范

- **先结构后内容**：所有加页、删页、调序（修改 `<p:sldIdLst>`）必须在编辑文本前完成；删除带动画的图形时同步清理 `<p:timing>`。
- **XML 解析器**：使用 `defusedxml.minidom`，避免 `xml.etree.ElementTree` 重写命名空间前缀导致文件损坏。
- **模板槽位清理**：实际数据少于模板占位数量时，必须整组删除多余的图片与文本框；首尾带空格的文本在 `<a:t>` 上加 `xml:space="preserve"`。
- **`python-pptx` 局限**：不支持直接复制页面；修改文字应赋给 `run.text` 而非 `text_frame.text`；不支持直接读取 SVG/EMF 图片。

### 6. 三层质量自检（QA）

- **内容质检**：无遗漏内容、无错别字、无残留占位符（如 `TODO`、`lorem`、`xxx`、`[insert]`）。
- **文件质检**：十六进制颜色无 `#`、无负值阴影、堆积图标签合法、组合图双轴声明完整、XML 特殊字符已转义。
- **视觉质检**：首查文字溢出或被截断；检查元素重叠与页脚碰撞；检查边距不小于 0.5 英寸、块间距不小于 0.3 英寸；检查文字与图标对比度；检查数字与单位未被拆行，跨页标题高度与图表标签样式一致。
