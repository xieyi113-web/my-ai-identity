# xlsx

基于官方 `xlsx` 技能规范提炼的电子表格（`.xlsx` / `.xlsm` / `.xltx` / `.csv` / `.tsv`）全流程制作、编辑、公式校验与财务建模指南，涵盖 `openpyxl` 编码避坑、跨平台公式兼容规则、重算核查及财务模型格式标准。

## When to Use

- 用户要求从零新建或基于外部数据源生成 `.xlsx`、`.csv` 等电子表格文件。
- 用户需要打开、读取、修改或修复既有 `.xlsx`、`.xlsm`、`.xltx`、`.csv`、`.tsv` 文件。
- 用户需要清洗或重构结构凌乱的表格数据为规范电子表格。
- 用户需要构建带动态公式、假设区与规范配色的财务或业务测算模型。

## Steps

### 1. 按任务类型选择技术路径

- **带公式与格式的新建/编辑**：使用 `openpyxl`。
- **大批量数据读写或清洗**：使用 `pandas`（`read_excel`、`to_excel`）。
- **完整读取模型（同时获取公式与数值）**：对同一文件执行两次 `load_workbook`（一次默认模式读公式，一次 `data_only=True` 读缓存值）。

### 2. 交付物核心规范

- **统一专业字体**：全表统一使用专业字体（英文 Arial、Times New Roman；中文配合系统通用无衬线字体）。
- **严禁硬编码计算结果**：所有汇总、比率与衍生指标必须写入 Excel 公式（如 `=SUM(B2:B9)`），绝不将静态计算值直接填入结果单元格。
- **零公式错误**：交付前确保公式零报错；若怀疑错误来自原文件，须用 `data_only=True` 加载原文件核实。
- **严格遵循用户口径**：工作表名、列标题与公式逻辑逐字对齐。
- **假设与常量留痕**：每项假设与硬编码数字均须通过批注或表尾注明来源。
- **区分新建模板与编辑旧表**：新建填报模板须附输入区图例及 1 行示例数据；编辑既有文件时原文件规范优先，仅在既有输入区写入，严禁擅自添加示例行。

### 3. 公式兼容与重算核查

- **优先高兼容函数**：优先使用 `SUMIFS`、`INDEX`、`MATCH`、`IFERROR`、`SUMPRODUCT`。
- **需加 `_xlfn.` 前缀的 6 个函数**：`_xlfn.TEXTJOIN`、`_xlfn.CONCAT`、`_xlfn.IFS`、`_xlfn.SWITCH`、`_xlfn.MAXIFS`、`_xlfn.MINIFS`，裸写会报 `#NAME?`。
- **禁用不兼容动态数组函数**：严禁使用 `XLOOKUP`、`XMATCH`、`SORT`、`FILTER`、`UNIQUE`、`SEQUENCE`；查找改用 `INDEX`/`MATCH`，排序筛选去重在 Python 侧完成后再写入。
- **先测后铺与重算**：铺开整表前先测 2 至 3 个核心公式核对取数范围；`openpyxl` 写入的公式不含缓存值，交付前须在本地 Excel 或 LibreOffice 中打开重算核验。

### 4. `openpyxl` 编码核心避坑清单

- **禁止保存 `data_only=True` 打开的工作簿**：会永久丢弃全部公式。
- **合并单元格写入**：仅向左上角锚点单元格赋值。
- **保留宏文件**：读取 `.xlsm` 必须传入 `keep_vba=True`。
- **含空格工作表跨表引用**：表名必须加单引号（如 `='Assumptions Inputs'!$B$5`）。
- **文本框、图形与切片器保护**：`openpyxl` 保存会丢失上述对象，修改前须检查 `xl/drawings/` 与 `xl/slicers/`。
- **显式设置数字格式**：每个新建公式单元格均须单独设置 `number_format`（日期、百分比、货币）。
- **图表防错配置**：设 `chart.roundedCorners = False`，图例与各标题设 `.overlay = False`，带坐标轴图表设 `x_axis.delete = False` 与 `y_axis.delete = False`；使用 `DateAxis` 时设 `chart.y_axis.crossAx = 500`。

### 5. 财务与测算模型规范（默认标准）

- **颜色编码**：蓝色字体（`0,0,255`）为硬编码输入；黑色为本表公式；绿色（`0,128,0`）为跨表引用；红色（`255,0,0`）为跨文件链接；黄色填充（`255,255,0`）为关键假设与待填单元格。
- **数字格式**：货币 `$#,##0`（表头注单位），零值显示 `-`，负数加括号；百分比 `0.0%`（底层存小数）；估值倍数 `0.0x`；年份存为文本。
- **模型结构**：每项假设独立单元格供公式引用；同行各期公式一致；可能为零的分母须加防除零保护。
