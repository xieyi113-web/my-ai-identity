# formal-report-ppt-v2

将原始材料、工作总结或业务数据转化为结构严密、视觉庄重、去 AI 味、可直接演示的正式汇报型演示文稿。

## When to Use

- 用户要求制作工作汇报、半年度或年度总结、专题汇报、管理层或董事会汇报 PPT。
- 用户提供长篇文档、数据表格或零散要点，希望提炼为结构化演示文稿。
- 用户需要跨电脑稳定演示的纯离线 HTML 幻灯片，或需要可二次编辑的 `.pptx` 文稿。

## Steps

### 1. 确认汇报定位与交付格式

- 识别汇报对象（领导班子、董事会、业务部门或外部合作方）与核心目的（决策请示、工作复盘、风险提示或方案宣贯）。
- 交付格式默认采用**纯离线单文件 HTML 幻灯片**（内联全部 CSS 与 JS，不依赖外部 CDN 或网络字体，确保在任意电脑双击即可原样播放）。
- 若用户明确要求可编辑文件或需套用单位标准母版，则按 `.pptx` 规范输出结构化内容与生成脚本（如 `python-pptx` 或 `pptxgenjs`）。

### 2. 构建金字塔逻辑与逐页大纲

- **结论先行**：封面之后优先安排“核心结论/总体概览”页，用 3 至 4 个核心指标或判断定调全文。
- **一页一主题**：每页顶部标题必须是提炼后的观点句（例如“一季度风险压降 15%，重点领域敞口可控”），末尾不加句号，避免使用空泛的目录词（如“工作情况”）。
- **严密论证**：重要论点遵循“依据—推理—结论”结构，数据保留原始口径，不估算、不臆测；若原始材料有缺失，在页面底部以注释标明。
- **文风规范**：采用正式、简练、庄重的公文表达，杜绝口语化、夸张修辞与空话套话。

### 3. 执行视觉与去“AI 味”排版规范

- **配色体系与明暗对比**：主色调采用深海蓝或政企蓝（如 `#0F2C59`、`#1B4965`），占 60% 至 70% 视觉权重；辅助色用沉稳灰（`#4A5568`、`#F7FAFC`），警示或重点数据使用克制的暗红或琥珀金（`#C53030`、`#B7791F`）。封面与封底采用深色背景，正文默认纯白（`#FFFFFF`）或浅灰，形成明暗夹心对比；严禁默认使用米黄/奶油底色（如 `#F5F5DC`、`#FAF0E6`、`#FFF8E1`）。
- **去“AI 味”视觉红线**：
  - 严禁在标题下方添加细装饰线（accent lines），改用留白或层级对比建立节奏。
  - 严禁添加通栏装饰色条、页面侧边竖条或卡片单侧彩色边框（single-side borders）；区分内容卡片请使用极浅底色、克制阴影或简洁图标。
  - 严禁花哨动画、霓虹渐变或无意义的装饰元素，动效仅限平滑淡入或无动画。
- **字号层级与底线**：
  - 标题大号加粗（PPTX 为 36-44pt，HTML 保持同等视觉比例），同类页面标题位置、字号与对齐方式必须完全一致。
  - 正文左对齐（严禁居中），单段不超过 3 行，**字号底线不低于 14pt**；注释/来源不低于 10pt。内容超出容器时，必须通过删减文字、扩大容器或拆页解决，严禁强行缩小字号突破底线。
- **版式与留白底线**：
  - 杜绝纯文字页，优先使用 KPI 指标卡、对比表格、双栏结构、原生图表或时间轴，并避免连续多页重复完全相同的版式。
  - 页面四周保留充足边距（PPTX 最小 0.5 英寸，HTML 保持宽裕内边距），模块间距全篇统一（0.3 至 0.5 英寸或等效像素），杜绝元素紧贴或大面积不均衡留白。
- **字体安全与交互（HTML 版）**：使用系统自带无衬线字体栈（如 `"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`）；支持键盘左右方向键、空格键翻页，底部提供页码指示与简洁导航栏，并内置打印/导出 PDF 样式（`@media print`）。

### 4. 生成交付与质量自检

生成完成后，按以下清单逐项核查：

- **离线可用性**：HTML 文件内无外部图片链接、无外部 CDN 脚本或样式表引用。
- **版面与防溢出核查**：16:9 宽屏比例下无文字溢出、无元素重叠、无页脚与正文碰撞、无数字与单位被拆行（如 `26` 与 `%` 分行）；跨页标题高度与图表标签样式保持一致。
- **去“AI 味”红线核查**：确认无标题下划线、无装饰色条或单侧彩边、无低于 14pt 的正文。
- **数据一致性与可追溯性**：正文、图表与汇总页的数值、单位和占比口径完全一致，关键结论均对应原始材料依据。

## Gotchas

- **避免大段复制原文**：PPT 是视觉辅助工具而非 Word 文档的翻版，必须对长文本做结构化拆解与要点提炼。
- **避免依赖外网资源**：在政企或会议室脱网环境下，引用外部 CDN 的 HTML 幻灯片会直接白屏或样式崩坏，必须保证 100% 本地自包含。
- **避免强行塞满页面**：宁可拆分为两页，也不要为了塞进更多文字而压缩边距或突破 14pt 正文字号底线。
